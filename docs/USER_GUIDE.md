# Metaphysics Reasoner User Guide

## Navigating the Dashboard
1. Input your birth details in the top bar.
2. Click **Generate Report**.
3. View the SVG chart on the left, and the Multi-Agent consensus and pattern analysis on the right.

## Chart Library
1. Click **Save Chart to Library** from the Dashboard.
2. Navigate to **Chart Library** to search or export your chart as JSON or HTML.
